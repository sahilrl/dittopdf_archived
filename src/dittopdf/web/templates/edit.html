Annotations are drawn on the page, so replacing them changes what the second PDF shows. Signature fields are copied unsigned.

Structure tree (tags)

Tags point into the page content. Copy them only if both PDFs have the same content (e.g. the second PDF is a re-saved copy); otherwise accessibility data becomes wrong.

File identifier (/ID)

Exact reproduction is done by a same-length substitution after writing and is verified; it is not possible for encrypted output.

Metadata consistency

e.g. a new Info Author also updates dc:creator, unless you set dc:creator yourself.

File structure




Keeping object numbers means dittopdf writes the file itself: the original's catalog, Info, pages, XMP and every copied object keep their numbers, the second PDF's objects take matching or free numbers, and object streams follow the original's layout. The file is verified before it is kept; otherwise qpdf writes it. Offsets are always computed for the new file.
